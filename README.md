# New Lead Roster

A browser-only lead formatter designed for GitHub Pages. It does not use a database, cookies, local storage, analytics, or network requests. Lead data lives only in the open tab's JavaScript memory and is erased on refresh or close.

## Publish with GitHub Pages

1. Upload `index.html` to the root of a GitHub repository.
2. Open **Settings → Pages**.
3. Under **Build and deployment**, select **Deploy from a branch**.
4. Select the `main` branch and `/ (root)`, then save.

For company use, obtain approval before publishing or using any tool that processes candidate information.
